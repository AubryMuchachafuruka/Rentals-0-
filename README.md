## ✨ Features

- **Landlord dashboard** — add / edit / delete listings (with photo picker), approve or
  reject tenant applications, mark payments received, occupancy + collections analytics.
- **Tenant dashboard** — search & filter listings, apply online, track application status,
  wishlist saved homes, lease & payment history.
- **Admin panel** — users table, approve/reject new listings, platform activity log.
- **Zimbabwean foundations** — Borrowdale, Avondale, Mount Pleasant, Glen Lorne,
  Greendale, Highlands, Ruwa, Waterfalls & The Avenues; boreholes, water tanks,
  prepaid ZESA, solar backup, boom gates, fibre — priced in US$.
- **Accessibility (WCAG 2.1 AA target)** — skip links, ARIA tabs/dialogs/tables,
  keyboard navigation, focus trapping & management, live-region announcements,
  AA contrast, reduced-motion support.
- Data persists per browser via `localStorage` (with in-memory fallback).

## 🚀 Enabling GitHub Pages

1. Open the repository on GitHub → **Settings** → **Pages**.
2. Source: **Deploy from a branch** → Branch: **main** · Folder: **/ (root)** → **Save**.
3. Wait ~1 minute, refresh — your live URL appears at the top of that page.
